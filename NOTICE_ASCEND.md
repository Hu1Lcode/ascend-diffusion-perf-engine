# Upstream attribution

This repository adapts the Sol-Engine branch of NVlabs/Sana, starting at commit
`bb60499af0e675095ff67424196d8c18e265f32a`. The upstream project and
authors are credited in `README.md` and its original documentation.

The Ascend adapter targets vLLM-Omni v0.28.0 at commit
`eb11446b7f2e30ca582f8aff3afe12e9a2e66f6c`. It does not vendor the
vLLM-Omni source; a pinned example is copied into ignored run artifacts at
runtime. Consult each upstream repository for its copyright and license notices.

The three checked-in I2V images are generated test inputs for this project.
